## 1. 프로젝트 요약

| 항목 | 내용 |
|---|---|
| 한 줄 요약 | 사용자 맞춤 주거지역·매물 추천과 매물 사진 화각 분석으로 합리적인 자취방 선택을 돕는 AI 서비스 |
| 기술 키워드 | Gradient Boosting 회귀(월세 예측), Learning-to-Rank(추천 순위), CNN 전이학습(EfficientNet-B0, 화각 추정), 지하철 그래프 최단경로, 부동산 공공데이터 |
| 팀 | KKC — 김태욱, 김상혁, 최한별 |

**목적·필요성** — 2026년 1~9월 전국 임대차 거래의 68.6%가 월세이고, 서울 원룸 월세는 평균 64만 원, 강남구 102만 원으로 지역 차이가 크다. 그런데 예산·통학·편의시설을 한 번에 비교해 지역을 고를 도구가 없고, 광각 매물 사진은 공간을 실제보다 넓어 보이게 한다.

**개요** — 예산과 통학지를 입력하면 실거래가 기반 월세 예측과 지하철 통학 시간으로 서울 주거지역·매물 순위를 매기고, 매물 사진의 화각을 추정해 표준 렌즈(1x)로 찍었을 때의 모습으로 복원한다. 조건을 조금 양보하면 얼마를 아낄 수 있는지도 제안한다.

**기대 효과** — 탐색 시간·비교 부담 감소, 사진으로 인한 공간 오인 예방. 화각 분석은 숙박·인테리어 사진 신뢰도 분석으로 확장 가능.

## 2. 목적 및 필요성

### 문제 인식
서울에서 자취방을 구하는 대학생·사회초년생은 제한된 예산 안에서 월세, 보증금, 교통 접근성을 함께 따져야 하지만 조건을 하나씩 따로 비교해야 한다. 광각 사진만으로는 실제 면적을 가늠하기도 어렵다.

### 기획 의도
예산과 생활 조건으로 AI가 서울 주거지역을 먼저 추천하고, 그 지역 매물의 가격·입지를 분석한다. 매물 사진은 화각을 추정해 1x 시야를 함께 보여준다.

### 시장 동향
- 국토교통부 「2026년 9월 주택 통계」(10.30 발표): 1~9월 누계 월세 비중 68.6%, 전년 대비 +6.0%p.
- 다방 「6월 다방여지도」: 2026년 6월 서울 연립·다세대 원룸 평균 월세 64만 원, 강남구 102만 원(약 1.6배).
- 서울시 「2024 서울시 주거실태조사」: 청년층 비율 관악구 45.2%, 광진구 33.2%, 마포구 32.7% — 일부 지역 집중.

### 경쟁 서비스 비교

| 서비스 | 하는 것 | 한계 |
|---|---|---|
| 직방·호갱노노 AI중개사 | 자연어 조건 → 아파트 단지 추천 | 아파트 위주, 원룸 수요층과 안 맞음 |
| 다방 AI방찾기 | 챗봇으로 원룸 매물 탐색 | 매물 탐색 중심, 지역 선추천 없음 |
| 네이버페이 부동산 VR투어 | 3D 내부·면적 실측 | 별도 촬영 필요, 일부 아파트만 |
| **KKC** | 지역 선추천 + 시세 비교 + 화각 복원 + 양보 제안 | — |

세 서비스 모두 광각 촬영 여부를 분석하지 않는다. KKC는 판별에서 그치지 않고 1x 시야를 복원해 보여주며, "통학 10분만 양보하면 월 약 8~14만 원 절약"(예시)처럼 조건과 비용 사이의 선택지를 제시한다.

## 3. 프로젝트 개요

### 적용 기술과 데이터

| 기술 | 역할 | 데이터 | 코드 |
|---|---|---|---|
| Gradient Boosting 회귀 | 지역별 월세(환산) 예측, 매물의 시세 대비 차이 | 국토교통부 전월세 실거래가 | `src/kkc/price/model.py` |
| Learning-to-Rank | 지역·매물 추천 순위 | 예측 월세, 통학 시간, 상가정보 기반 반경 내 편의점·마트·병원 수 | `src/kkc/ranking/rank.py` |
| EfficientNet-B0 전이학습 | 실내 사진 화각(°) 회귀 → 가운데 크롭으로 1x 시야 복원 | 팀 직접 촬영 실내 사진(0.5x·1x) | `src/kkc/vision/fov.py` |

### 주요 기능
1. 예산·선호 조건 입력
2. AI 기반 서울 주거지역 추천
3. 지역별 월세 예측 및 매물 가격 비교
4. 매물 사진 광각 가능성 분석 및 표준 시야 복원
5. "이것만 양보하면" 제안
6. 가격·위치·교통·사진 분석 종합 매물 추천

### 서비스 방식
- 웹 서비스. 조건 입력 → 추천 지역 확인 → 후보 매물 가격·사진 분석 비교.
- 지역별 예측 월세·통학 시간은 미리 계산해 두어 조건을 바꾸면 순위가 즉시 다시 계산된다.
- 매물 정보·사진은 사용자 직접 등록 또는 사용 허가 데이터만 사용. 외부 플랫폼 자동 연동은 추후 확장.
- 화각 결과는 허위 여부가 아닌 "실제보다 넓어 보일 수 있음" 참고 정보로 제공.

## 4. 기대효과 및 활용 방안

- **사용자**: 탐색 시간·비교 부담 감소, 공간 오인 방지, 통학 시간과 주거비 사이의 근거 있는 선택.
- **비즈니스**: 부동산 플랫폼에 지역 추천·사진 분석 기능으로 적용, 매물 신뢰성 차별화.
- **개발자**: 공공데이터 분석, ML 가격 예측, 딥러닝 이미지 모델, 추천 시스템 통합 경험.
- **활용**: 대학생·사회초년생용 서울 자취방 추천 웹서비스 → 플랫폼 데이터 연동으로 실매물 추천 확대. 화각 추정·복원은 숙박·인테리어 사진 신뢰도 분석으로 확장.

## 5. 구현 계획 (초안)

### 핵심 설계 결정
1. **환산 월세로 통일** — 보증금이 매물마다 달라 `월세 + 보증금 × 전환율 / 12`로 맞춰 학습·비교한다.
2. **추천은 2단계** — 선호 데이터가 없는 초기엔 가중합 점수(예측 월세·통학·편의시설)로 시작하고, 사용자 선택 로그가 쌓이면 LightGBM LambdaRank로 교체한다.
3. **화각 복원 공식** — 직선 투영 가정에서 크롭 비율 = tan(69.4°/2) / tan(θ추정/2). 0.5x(약 108°)면 가로·세로 절반을 잘라 확대한다. 학습 라벨은 EXIF 35mm 환산 초점거리에서 계산한다.
4. **통학 그래프** — 노드 = (역, 호선). 같은 역 다른 호선은 환승 소요시간으로 연결해 다익스트라 한 번으로 모든 역까지 시간을 구한다.

### 일정 (예시, 8주)

| 주차 | 김태욱 | 김상혁 | 최한별 |
|---|---|---|---|
| 1–2 | 실거래가 수집·정제 | 지하철 그래프 적재, 통학 시간 표 | 촬영 프로토콜, 0.5x/1x 사진 쌍 수집 |
| 3–4 | GBR 학습, MAE 측정 | 편의시설 집계, 가중합 추천 | EfficientNet-B0 학습 |
| 5–6 | 시세 대비 비교 API | Streamlit 화면, 양보 제안 | 복원 품질 평가, 모델 연결 |
| 7–8 | 통합 테스트 · 발표 자료 | | |

### 평가 지표
- 월세 예측: 검증 MAE(만원), 자치구별 오차
- 추천: 선호 데이터 수집 후 NDCG@5
- 화각: 추정 MAE(°), 0.5x/1x 이진 분류 정확도
